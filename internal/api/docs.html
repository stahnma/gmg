GMG API

HTTP API for monitoring and controlling the grill. Paths are relative to this server. Cross-origin requests are allowed.

Endpoints

RequestDescription
GET/api/statusCurrent grill status, read from the grill (Status).
PUT/api/powertoggleToggle power.
PUT/api/poweronTurn the grill on.
PUT/api/poweroffTurn the grill off.
PUT/api/temperature/grill/{°F}Set the target grill temperature. The grill must be on.
PUT/api/temperature/food/{°F}Set the target food temperature. The grill must be on.
GET/api/temperature/history?since={unix seconds}Recorded temperatures at or after since, oldest first (History row). A missing or invalid since returns [].
GET/api/eventsLive event stream (Server-Sent Events).
GET/apiThis page.

Command responses

Commands (PUT) return 200 with the plain-text body OK. Errors are plain text:

  • 400 — the grill can't accept the command, e.g. Cannot set grill temperature when the grill is off! or an invalid temperature.
  • 500 — the grill didn't respond.
  • 404 — unknown path or wrong method.

Status

{
  "state": "on",
  "_hex": "5552…",
  "isOn": true,
  "currentGrillTemp": 224,
  "desiredGrillTemp": 225,
  "currentFoodTemp": 140,
  "desiredFoodTemp": 165,
  "fanModeActive": false,
  "lowPelletAlarmActive": false
}
FieldDescription
stateon, off, fan mode (cooling down after power off) or unknown.
_hexRaw grill response, hex encoded (for debugging).
isOn, fanModeActiveShortcuts for state.
currentGrillTemp, desiredGrillTempGrill temperature and target, °F.
currentFoodTemp, desiredFoodTempFood probe temperature and target, °F.
lowPelletAlarmActiveThe grill reports low pellets.

History row

[{ "temperature_log_id": 1, "timestamp": 1764172800, "grill_temperature": 224, "food_temperature": 140 }]

timestamp is Unix seconds. food_temperature is null when no probe reading was recorded.

Event stream

GET /api/events sends Server-Sent Events. The latest status is sent on connect.

EventData
statusA Status, on every poll of the grill.
alertAn Alert, when one fires.

Alert

{
  "type": "targetGrillTempReached",
  "name": "Target Grill Temperature Reached",
  "reason": "Grill temperature has reached target temperature of 225",
  "beep": "alerts/targetGrillTempReached.mp3",
  "level": "info"
}

type is targetGrillTempReached, targetFoodTempReached or lowPelletAlarmActive. level is info, warning or error. beep is the sound file to play; it is omitted when audio alerts are disabled.

Examples

curl http://HOST/api/status
curl -X PUT http://HOST/api/temperature/grill/225
curl "http://HOST/api/temperature/history?since=$(( $(date +%s) - 3600 ))"
curl -N http://HOST/api/events
